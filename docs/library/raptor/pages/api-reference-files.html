Files API

The Files API manages file uploads within nests. Uploaded files are available as context for governed interactions. Images are processed with OCR automatically.

POST /api/nests/{nest_id}/files

Upload a file to a nest via multipart form data. Maximum file size is 10 MB. Image files (PNG, JPG, TIFF, PDF) are processed with OCR and the extracted text is made available as context.

Authentication: Required (any mode)

Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| nest_id | string | Target nest ID |

Request

Multipart form data with a file field.

curl -X POST \
  -H "X-Raptor-Key: rpt_live_abc123def456" \
  -F "file=@report.pdf" \
  https://raptor.harpyits.com/api/nests/nest_f7a2c9e1/files

Response Body

{
  "ok": true,
  "file": {
    "id": "file_abc123",
    "nest_id": "nest_f7a2c9e1",
    "filename": "report.pdf",
    "content_type": "application/pdf",
    "size_bytes": 245760,
    "ocr_available": true,
    "created_at": "2026-05-21T18:00:00Z"
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | No file provided or invalid format |
| 401 | unauthorized | No valid authentication |
| 404 | not_found | Nest does not exist |
| 413 | payload_too_large | File exceeds 10 MB limit |

GET /api/files/{file_id}

Get metadata for a specific file.

Authentication: Required (any mode)

Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| file_id | string | File ID |

Response Body

{
  "ok": true,
  "file": {
    "id": "file_abc123",
    "nest_id": "nest_f7a2c9e1",
    "filename": "report.pdf",
    "content_type": "application/pdf",
    "size_bytes": 245760,

    "ocr_text_length": 12480,
    "created_at": "2026-05-21T18:00:00Z",
    "revoked": false
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |
| 404 | not_found | File does not exist |

DELETE /api/files/{file_id}

Revoke a file. This is a soft-delete: the file is no longer available as context for new interactions, but the audit record of its upload and usage is retained for governance compliance.

Authentication: Required (any mode)

Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| file_id | string | File ID |

Response Body

{
  "ok": true,
  "revoked_at": "2026-05-21T19:00:00Z"
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |
| 404 | not_found | File does not exist |
| 409 | conflict | File already revoked |

POST /api/files/content

Upload a file via JSON with base64-encoded content. Designed for MCP integrations and SDK usage where multipart form data is not convenient.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| nest_id | string | Yes | Target nest ID |
| filename | string | Yes | Original filename |
| content_type | string | Yes | MIME type |
| content | string | Yes | Base64-encoded file content |

{
  "nest_id": "nest_f7a2c9e1",
  "filename": "data.csv",
  "content_type": "text/csv",
  "content": "bmFtZSxhbW91bnQKQWxwaGEsMTAwCkJldGEsMjAw..."
}

Response Body

{
  "ok": true,
  "file": {
    "id": "file_ghi789",
    "nest_id": "nest_f7a2c9e1",
    "filename": "data.csv",
    "content_type": "text/csv",
    "size_bytes": 1024,
    "ocr_available": false,
    "created_at": "2026-05-21T18:10:00Z"
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Missing required fields or invalid base64 |
| 401 | unauthorized | No valid authentication |
| 404 | not_found | Nest does not exist |
| 413 | payload_too_large | Decoded content exceeds 10 MB limit |
