TypeScript SDK

Install the Raptor SDK, send governed messages, and consume trust-boundary types end-to-end in TypeScript.

TypeScript SDK

The @raptor/sdk package is a thin, typed fetch wrapper around the Raptor REST API. It preserves trust-boundary types end-to-end — from the API response through your application code — with zero runtime dependencies.

1. Install

npm install @raptor/sdk

Requires Node.js 18+ (uses the built-in fetch API).

2. Initialize the client

import { RaptorClient } from "@raptor/sdk";


const raptor = new RaptorClient({
  baseUrl: "https://raptor.harpyits.com",
  auth: { type: "access_token", token: "rpt_your_key" },
});

The SDK supports multiple auth modes:

// Clerk JWT (browser or server)
auth: { type: "clerk", getToken: () => clerk.session.getToken() }


// Static Clerk token
auth: { type: "clerk", token: "eyJhbG..." }



// API key
auth: { type: "access_token", token: "rpt_a1b2c3d4..." }



// Founder key
auth: { type: "founder_key", key: "your_founder_key" }

3. Send a governed message

const response = await raptor.chat("What are the risks of deploying on Friday?");


console.log(response.reply);
console.log(response.trust_boundary.primary); // "inferred" | "confirmed" | ...
console.log(response.decision_type);          // "respond" | "propose_action" | ...

The ChatResponse type carries the full response shape including reply, trust_boundary, segments, decision_type, and audit_trail. All fields are typed.

Send to a specific nest

const response = await raptor.chat("proceed", { nestId: "nest-uuid" });

4. Read trust boundaries with TypeScript types

The SDK exports trust-boundary types as first-class citizens:

import type {
  TrustBoundary,
  TrustSegment,
  TrustLevel,
  DecisionSupport,
  ConfidenceLevel,
} from "@raptor/sdk";

Trust levels form a hierarchy: confirmed > executed > retrieved > inferred > unknown. Every response carries a primary trust level plus per-segment boundaries:

function handleResponse(response: ChatResponse) {
  const boundary: TrustBoundary = response.trust_boundary;


// Primary boundary — the overall trust level for the response
  if (boundary.primary === "confirmed" || boundary.primary === "executed") {
    actOnResult(response.reply);
    return;
  }



// Per-segment boundaries — individual parts may have different trust levels
  for (const segment of response.segments ?? []) {
    if (segment.boundary === "confirmed") {
      renderVerified(segment);
    } else {
      renderWithCaveat(segment);
    }
  }
}

5. Handle decision support

When the decision engine returns structured recommendations, the DecisionSupport type gives you the five-part contract:

import type { DecisionSupport } from "@raptor/sdk";


function renderDecision(ds: DecisionSupport) {
  console.log(ds.recommendation);  // What the engine recommends
  console.log(ds.basis);           // Why it recommends it
  console.log(ds.confidence);      // "CLEAR" | "RECOMMENDED" | "ADVISORY" | "INSUFFICIENT"
  console.log(ds.risk_if_wrong);   // What happens if the recommendation is wrong
  console.log(ds.alternatives);    // Other options considered
}

6. Work with nests

// Create a nest
const { nest } = await raptor.createNest("deploy-review-q3");


// List nests
const { nests } = await raptor.listNests();



// Get nest details
const { nest: detail } = await raptor.getNest(nest.id);



// Archive a nest
await raptor.archiveNest(nest.id);

7. Retrieve chat history

const history = await raptor.getChatHistory("nest-uuid");


for (const message of history.messages) {
  console.log(message.role, message.content);
  // Trust boundaries are preserved on historical messages
  console.log(message.trust_boundary?.primary);
}



// Paginate backward
const older = await raptor.getChatHistory("nest-uuid", {
  before: history.messages[history.messages.length - 1].id,
});

8. Static helpers

The client includes static methods for common trust-boundary operations:

// Group segments by trust level
const grouped = RaptorClient.segmentsByTrust(response);
const confirmed = grouped.get("confirmed") ?? [];


// Quick check for high-trust content
if (RaptorClient.hasHighTrust(response)) {
  // Response is confirmed or executed — safe to act on
}

9. Error handling

import { RaptorError } from "@raptor/sdk";


try {
  await raptor.chat("do something risky");
} catch (err) {
  if (err instanceof RaptorError) {
    console.log(err.status);         // HTTP status code
    console.log(err.code);           // Machine-readable error code
    console.log(err.detail);         // Additional context
    console.log(err.correlationId);  // Request trace ID for support
  }
}

10. Health check

const healthy = await raptor.isHealthy();
if (!healthy) {
  // Raptor instance is unreachable or unhealthy
}
