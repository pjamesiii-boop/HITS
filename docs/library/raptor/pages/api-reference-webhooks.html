Webhooks API

Subscribe to governance events with authenticated webhook delivery.

Webhooks API

The Webhooks API lets you subscribe to governance events in real time. Raptor delivers events to your HTTPS endpoint with HMAC-SHA256 signatures for verification.

Event Types

| Event | Fired when |
|-------|-----------|
| governance.allowed | A governance evaluation permitted an action |
| governance.denied | A governance evaluation denied an action |
| response.created | A governed response was delivered |
| execution.completed | A workflow execution finished |
| policy.activated | A new policy was activated |

Delivery

Each webhook delivery includes:

  • HMAC-SHA256 signature in the X-Raptor-Signature header, computed over the raw request body using your webhook secret.
  • Retry on failure: Raptor retries failed deliveries (non-2xx response or timeout) with exponential backoff up to 3 attempts over 1 hour.
  • Timeout: Your endpoint must respond within 10 seconds.

Signature Verification

import hmac
import hashlib


def verify_signature(payload_body: bytes, secret: str, signature: str) -> bool:
    expected = hmac.new(
        secret.encode("utf-8"),
        payload_body,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)

POST /api/webhooks

Create a webhook subscription. A secret is auto-generated and returned in the response. Store it securely -- it is only shown once.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| url | string | Yes | HTTPS endpoint URL |
| events | string[] | Yes | Event types to subscribe to |

{
  "url": "https://example.com/webhooks/raptor",
  "events": ["governance.allowed", "governance.denied", "response.created"]
}

Response Body

{
  "ok": true,
  "webhook": {
    "id": "wh_abc123",
    "url": "https://example.com/webhooks/raptor",
    "events": ["governance.allowed", "governance.denied", "response.created"],
    "secret": "whsec_abc123def456ghi789",
    "active": true,
    "created_at": "2026-05-21T18:00:00Z"
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Missing URL, invalid URL scheme, or unknown event types |
| 401 | unauthorized | No valid authentication |

PATCH /api/webhooks/{id}

Update a webhook subscription. You can change the URL, event subscriptions, or active status.

Authentication: Required (any mode)

Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| id | string | Webhook ID |

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| url | string | No | New HTTPS endpoint URL |
| events | string[] | No | Updated event types |
| active | boolean | No | Enable or disable delivery |

{
  "events": ["governance.allowed", "governance.denied", "response.created", "execution.completed"],
  "active": true
}

Response Body

{
  "ok": true,
  "webhook": {
    "id": "wh_abc123",
    "url": "https://example.com/webhooks/raptor",
    "events": ["governance.allowed", "governance.denied", "response.created", "execution.completed"],
    "active": true,
    "updated_at": "2026-05-21T19:00:00Z"
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Invalid URL or unknown event types |
| 401 | unauthorized | No valid authentication |
| 404 | not_found | Webhook does not exist |
