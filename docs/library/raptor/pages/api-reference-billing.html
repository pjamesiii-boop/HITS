Billing API

The Billing API manages subscription checkout, customer portal access, and usage tracking. Billing is powered by Stripe.

POST /api/billing/checkout

Create a Stripe Checkout session for a new subscription or tier upgrade. Returns a URL to redirect the user to Stripe's hosted checkout page.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| tier | string | Yes | Subscription tier: team or growth |

{
  "tier": "team"
}

Response Body

{
  "ok": true,
  "checkout_url": "https://checkout.stripe.com/c/pay/cs_live_abc123...",
  "session_id": "cs_live_abc123"
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Invalid tier value |
| 401 | unauthorized | No valid authentication |
| 409 | conflict | Tenant already on requested tier |

GET /api/billing/portal

Get a Stripe Customer Portal URL. Redirects the user to manage their subscription, payment methods, and invoices.

Authentication: Required (any mode)

Response Body

{
  "ok": true,
  "portal_url": "https://billing.stripe.com/p/session/bps_abc123..."
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |
| 404 | not_found | No Stripe customer record for this tenant |

GET /api/billing/usage

Get usage summary for the current billing period.

Authentication: Required (any mode)

Response Body

{
  "ok": true,
  "usage": {
    "tier": "team",
    "period_start": "2026-05-01T00:00:00Z",
    "period_end": "2026-06-01T00:00:00Z",
    "responses": {
      "count": 1247,
      "limit": 5000
    },
    "files_uploaded": {
      "count": 34,
      "storage_bytes": 52428800
    },
    "executions": {
      "count": 89
    }
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |

POST /api/billing/webhook

Stripe webhook handler. This endpoint receives events from Stripe to synchronize subscription state. It is not called directly by API consumers.

Authentication: Stripe signature verification (via Stripe-Signature header)

Handled Events

| Stripe Event | Raptor Action |
|--------------|---------------|
| checkout.session.completed | Activate subscription |
| customer.subscription.updated | Sync tier changes |
| customer.subscription.deleted | Deactivate subscription |
| invoice.payment_failed | Flag payment issue |

Request Body

Standard Stripe webhook event payload. See Stripe webhook documentation.

Response Body

{
  "ok": true,
  "received": true
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Invalid Stripe signature |
