Quickstart

Get your first governed AI response in under 5 minutes.

Quickstart

Raptor is a deterministic governance substrate for AI applications. Every AI response passes through classification, policy enforcement, and cryptographic attestation before it reaches the user.

This guide covers two paths: cloud signup and self-hosted Docker.

Cloud

  1. Sign up at raptor.dev with Google, GitHub, Microsoft, or email.
  2. Create an organization and connect at least one AI provider (Anthropic recommended).
  3. Copy your API key from Settings. It starts with rpt_.

Your base URL is https://api.raptor.dev.

Self-Hosted (Docker)

Prerequisites

  • Docker and Docker Compose v2+
  • At least one AI provider API key (Anthropic, OpenAI, Gemini, or Together AI)

Setup

git clone https://github.com/pjamesiii/raptor.git && cd raptor
cp .env.example .env

Edit .env and set two required values:

RAPTOR_ACCESS_TOKEN=a-strong-random-token
ANTHROPIC_API_KEY=sk-ant-...

Start the stack:

docker compose up -d

Three services come up:

| Service | Port | Purpose |
|---------|------|---------|
| Control Panel | localhost:4000 | API and workspace UI |
| MCP Server | localhost:4001 | Claude Desktop / Cursor integration |
| PostgreSQL | localhost:5432 | Governance event store |

Verify the stack is healthy:

curl http://localhost:4000/api/health

{"status":"ok"}

Send your first governed message

curl -X POST http://localhost:4000/api/chat \
  -H "Content-Type: application/json" \
  -H "X-Raptor-Token: your-access-token" \
  -d '{"message": "Is this deployment verified?"}'

For cloud, replace localhost:4000 with api.raptor.dev and use your rpt_ API key:

curl -X POST https://api.raptor.dev/api/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer rpt_your_api_key" \
  -d '{"message": "Is this deployment verified?"}'

The response includes:

  • reply -- the AI's governed response text
  • trust_boundary -- classification: confirmed, executed, retrieved, likely, or uncertain
  • segments -- per-claim trust boundaries within the response
  • decision_support -- confidence level, recommendation, basis, and risk assessment
  • audit_trail -- the 4-event governance chain for this request

See Understanding Your First Response for a full breakdown.

What just happened?

  1. Your message entered the decision engine (classifier + confidence rules).
  2. Governance middleware checked capabilities, policies, and budgets.
  3. The AI generated a response in the proposal layer.
  4. The commit layer structured the response with per-claim trust boundaries.
  5. Everything was recorded in the hash-chained event log.

Every response follows this exact process. The process does not vary.
