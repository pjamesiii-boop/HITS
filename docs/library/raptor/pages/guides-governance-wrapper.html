Pattern 1: Governance Wrapper

The simplest integration — wrap your existing AI calls with Raptor's governance layer.

When to use

  • You have an existing AI application that works
  • You need governance, audit trails, and trust boundaries
  • You don't want to change your AI orchestration logic

Architecture

Your App → Raptor API → Your AI Provider
                ↓
         Governance check
         Trust boundary assignment
         Hash-chained audit event
                ↓
         Structured response back to your app

Integration

1. Route your AI calls through Raptor

Instead of calling your provider directly:

// Before: direct to provider
const response = await anthropic.messages.create({ ... });


// After: through Raptor
const response = await fetch('https://your-raptor.com/api/chat', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer rpt_your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ message: userInput })
});

2. Read the trust boundary

const data = await response.json();


// Every response tells you how much to trust it
if (data.trust_boundary.actionability.level === 'safe') {
  // Safe to act on
  showToUser(data.reply);
} else if (data.trust_boundary.actionability.level === 'blocked') {
  // Needs review
  escalateToHuman(data.reply, data.trust_boundary);
}

3. Use the audit trail

Every response is automatically logged in the hash-chained event store. Query it:

GET /api/nests/{nestId}/governance    # Governance decisions
GET /api/executions/{id}/trace        # Full execution chain
GET /api/tenant/audit/export          # Complete audit export

What you get

  • Trust boundaries on every response (no code changes to your AI logic)
  • Hash-chained audit trail (every response traceable)
  • Governance enforcement (policies control what AI can do)
  • Decision support (confidence levels, recommendations)
  • Billing metering (per governed response)
