Environment Variables

Complete reference for all Raptor configuration variables, organized by category.

Environment Variables

All configuration is done through environment variables. Set them in a .env file for Docker Compose, or inject them through your secret manager in production.

Start from the provided template:

cp .env.example .env

Required

These must be set for Raptor to start.

| Variable | Description | Example |
|---|---|---|
| DATABASE_URL | PostgreSQL 16+ connection string. The migrate container and control-panel both use this to connect. | postgresql://raptor:secret@postgres:5432/raptor?sslmode=disable |
| RAPTOR_ACCESS_TOKEN | Operator access token for API authentication. Used with X-Raptor-Token header or Authorization: Bearer header. Must be a strong, unique string. | rpt_a1b2c3d4e5f6... |

At least one AI provider key is also required. See Providers below.

Authentication

Raptor supports three authentication modes: token-only, Clerk SSO, and Founder Key. Token auth (RAPTOR_ACCESS_TOKEN) is always active. Clerk and Founder Key are layered on top for production use.

Clerk SSO

| Variable | Required | Description | Example |
|---|---|---|---|
| CLERK_SECRET_KEY | For SSO | Clerk backend secret key. Enables SSO/OAuth authentication. | sk_live_abc123... |
| CLERK_PUBLISHABLE_KEY | For SSO | Clerk frontend publishable key. Used by the Preact UI. | pk_live_abc123... |
| CLERK_DOMAIN | For SSO | Your Clerk instance domain. | your-app.clerk.accounts.dev |
| RAPTOR_ALLOW_TOKEN_FALLBACK | No | When Clerk is configured, allow token auth as a fallback. Default: false. | false |

Founder Key

| Variable | Required | Description | Example |
|---|---|---|---|
| RAPTOR_FOUNDER_KEY_HASH | No | SHA-256 hash of the founder key. Enables /api/auth/founder login endpoint. | e3b0c44298fc... |

AI Providers

At least one provider key must be set. Raptor uses configured providers for inference and automatically detects available providers at startup.

| Variable | Provider | Models |
|---|---|---|
| ANTHROPIC_API_KEY | Anthropic | Claude family |
| OPENAI_API_KEY | OpenAI | GPT-4o family |
| GEMINI_API_KEY | Google | Gemini family |
| TOGETHER_API_KEY | Together AI | Llama, Mixtral, open models |

Check which providers are active at runtime:

curl http://localhost:4000/api/runtime/config

See the Providers guide for failover behavior and pricing.

Server

| Variable | Required | Default | Description |
|---|---|---|---|
| RAPTOR_ENV | No | dev | Set to production for production deployments. Controls logging level, error verbosity, and security defaults. |
| CONTROL_HOST | No | localhost | Bind address. Set to 0.0.0.0 inside containers. The Docker Compose file sets this automatically. |
| CONTROL_PORT | No | 4000 | HTTP listen port for the control-panel. |

MCP Server

| Variable | Required | Default | Description |
|---|---|---|---|
| MCP_PORT | No | 4001 | Listen port for the MCP server. |
| RAPTOR_URL | No | http://localhost:4000 | Internal URL the MCP server uses to reach the control-panel. In Docker Compose, this is set to http://control-panel:4000. |
| MCP_PUBLIC_URL | No | http://localhost:4001 | Public-facing URL for the MCP server. Used in tool discovery responses. |

Billing (Stripe)

All Stripe variables are optional. Omit them entirely for free-tier-only operation.

| Variable | Required | Description |
|---|---|---|
| STRIPE_SECRET_KEY | For billing | Stripe API secret key. |
| STRIPE_WEBHOOK_SECRET | For billing | Stripe webhook signing secret for verifying inbound events. |
| STRIPE_PRICE_ID_INDIVIDUAL | For billing | Stripe Price ID for the Individual plan. |
| STRIPE_PRICE_ID_TEAM | For billing | Stripe Price ID for the Team plan. |
| STRIPE_PRICE_ID_GROWTH | For billing | Stripe Price ID for the Growth plan. |
| STRIPE_PRICE_ID_CREDIT_PURCHASE | For billing | Stripe Price ID for one-time credit purchases. |
| STRIPE_PRICE_ID_CREDIT_AUTOTOPUP | For billing | Stripe Price ID for automatic credit top-ups. |

Signing

| Variable | Required | Default | Description |
|---|---|---|---|
| RAPTOR_SIGNING_PRIVATE_KEY | No | None | Ed25519 private key for build-time attestation signing. When set during docker build, the binary is signed and an .attestation.json file is embedded in the image. Verify with raptor-verify. |

Artifact Storage

| Variable | Required | Default | Description |
|---|---|---|---|
| RAPTOR_ARTIFACT_BACKEND | No | local | Storage backend for artifacts. Options: local, r2. |
| RAPTOR_ARTIFACT_ROOT | No | data/artifacts | Local filesystem path for artifact storage (when backend is local). |
| RAPTOR_R2_BUCKET | No | None | Cloudflare R2 bucket name (when backend is r2). |
| RAPTOR_SCANNER_ENABLED | No | true | Enable artifact integrity scanning. |

Classifier Shadow

| Variable | Required | Default | Description |
|---|---|---|---|
| RAPTOR_CLASSIFIER_SHADOW_ENABLED | No | false | Enable shadow classifier for evaluation. Does not affect production decisions. |
| RAPTOR_CLASSIFIER_SHADOW_PROVIDER | No | None | Provider to use for shadow classification. |

Docker Compose

These variables are used only by the Docker Compose file, not by the application directly.

| Variable | Required | Default | Description |
|---|---|---|---|
| POSTGRES_PASSWORD | No | raptor_dev | Password for the bundled PostgreSQL container. Change this in production. |
