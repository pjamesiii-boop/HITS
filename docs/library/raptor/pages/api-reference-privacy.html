Privacy API

The Privacy API provides GDPR-compliant data governance: portable data export, right-to-erasure, consent management, and configurable retention policies.

GET /api/privacy/export

Export all personal data associated with the authenticated user in a portable JSON format. Implements GDPR Article 20 (right to data portability). The export covers 12 data tables.

Authentication: Required (any mode)

POST /api/privacy/delete

Request right-to-erasure (GDPR Article 17). Requires a typed confirmation string to prevent accidental deletion.

Personal data is deleted. Immutable governance records (audit trail, hash chain entries) are anonymized rather than deleted to preserve system integrity.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| confirmation | string | Yes | Must be exactly "DELETE MY DATA" |

{
  "confirmation": "DELETE MY DATA"
}

Response Body

{
  "ok": true,
  "deletion": {
    "status": "processing",
    "requested_at": "2026-05-21T18:00:00Z",
    "estimated_completion": "2026-05-21T18:05:00Z",
    "scope": {
      "deleted": [
        "profile",
        "messages",
        "files",
        "artifacts",
        "api_keys",
        "webhooks",
        "consent_records"
      ],
      "anonymized": [
        "governance_events",
        "audit_log",
        "hash_chain_entries",
        "execution_records",
        "billing_records"
      ]
    }
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Confirmation string does not match |
| 401 | unauthorized | No valid authentication |

POST /api/privacy/consent

Update consent preferences. Required consents (TOS, privacy policy, data processing) must be true for continued platform access. Optional consents can be toggled freely.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| terms_of_service | boolean | No | TOS consent (must be true to use platform) |
| privacy_policy | boolean | No | Privacy policy consent (must be true to use platform) |
| data_processing | boolean | No | Data processing consent (must be true to use platform) |
| analytics | boolean | No | Analytics data collection |
| marketing | boolean | No | Marketing communications |
| model_training | boolean | No | Allow data use for model training |

{
  "analytics": true,
  "marketing": false,
  "model_training": false
}

Response Body

{
  "ok": true,
  "consent": {
    "required": {
      "terms_of_service": { "granted": true, "granted_at": "2026-01-15T10:00:00Z" },
      "privacy_policy": { "granted": true, "granted_at": "2026-01-15T10:00:00Z" },
      "data_processing": { "granted": true, "granted_at": "2026-01-15T10:00:00Z" }
    },
    "optional": {
      "analytics": { "granted": true, "granted_at": "2026-05-21T18:00:00Z" },
      "marketing": { "granted": false, "granted_at": null },
      "model_training": { "granted": false, "granted_at": null }
    }
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Required consent set to false |
| 401 | unauthorized | No valid authentication |

PUT /api/privacy/retention

Update data retention policies. Governance events cannot be set below the regulatory minimum.

Authentication: Required (Founder Key or admin)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| messages | string | No | Retention period for chat messages |
| files | string | No | Retention period for uploaded files |
| audit_log | string | No | Retention period for audit log entries |
| governance_events | string | No | Retention period for governance events (minimum: 5y) |
| executions | string | No | Retention period for execution records |
| artifacts | string | No | Retention period for artifacts |

Valid retention values: 30d, 90d, 1y, 2y, 3y, 5y, indefinite

{
  "messages": "2y",
  "files": "1y",
  "audit_log": "5y",
  "governance_events": "indefinite",
  "executions": "3y",
  "artifacts": "2y"
}

Response Body

{
  "ok": true,
  "retention": {
    "messages": "2y",
    "files": "1y",
    "audit_log": "5y",
    "governance_events": "indefinite",
    "executions": "3y",
    "artifacts": "2y"
  },
  "updated_at": "2026-05-21T18:00:00Z"
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Invalid retention value or governance_events below minimum |
| 401 | unauthorized | No valid authentication |
| 403 | forbidden | Not an admin user |
