Chat API

The Chat API is the primary interface for governed AI interaction. Every message passes through the decision engine, governance layer, and trust classifier before a response is returned.

POST /api/chat

Send a governed message. The message is classified, routed through governance, and returned with trust-boundary annotations.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| message | string | Yes | The user's message |
| conversation_id | string | No | Nest ID to scope the conversation. Defaults to "default". |

{
  "message": "What was Q2 revenue and how does it compare to forecast?",
  "conversation_id": "nest_f7a2c9e1"
}

Response Fields

| Field | Type | Description |
|-------|------|-------------|
| ok | boolean | true on success |
| reply | string | The governed response text |
| decision_type | string | How the engine classified the intent. One of: respond, ask, propose_action, execute_confirmed_action |
| trust_boundary | object | Composite trust classification for the full response |
| trust_boundary.primary | string | Highest trust level: confirmed, executed, retrieved, inferred, unknown |
| trust_boundary.sublabel | string | Human-readable summary of segment verification |
| trust_boundary.actionability | object | Whether the response is safe to act on |
| trust_boundary.provenance | object | Execution ID and input hash for audit chain |
| segments | array | Individual response segments with independent trust levels |
| segments[].boundary | string | Trust level for this segment |
| segments[].text | string | The text content of this segment |
| segments[].basis | string | What produced this segment: model_response, workflow_execution, pbc_action, file_content, cryptographic_verification |
| decision_support | object | Structured decision support contract |
| decision_support.confidence | string | CLEAR, RECOMMENDED, ADVISORY, or INSUFFICIENT |
| decision_support.recommendation | string | What the engine recommends |
| decision_support.basis | string | Evidence backing the recommendation |
| decision_support.risk_if_wrong | string | What goes wrong if this recommendation is incorrect |
| decision_support.alternatives | array | Other options considered |
| audit_trail | array | Ordered list of governance checkpoints the request passed through |

Decision Types

| Type | Meaning |
|------|---------|
| respond | Informational response, no action proposed |
| ask | Clarification needed before proceeding |
| propose_action | Action proposed, awaiting user confirmation |
| execute_confirmed_action | Previously confirmed action executed |

Error Codes

| Status | Error | When |
|--------|-------|------|
| 400 | validation_error | Missing message field |
| 401 | unauthorized | No valid authentication |
| 403 | governance_denied | Policy blocked the message |
| 429 | rate_limited | Request rate exceeded |

POST /api/chat/reset

Reset the conversation context for the current session. History is preserved but the model context window is cleared.

Authentication: Required (any mode)

Request Body

No body required. Send an empty JSON object or omit the body.

{}

Response Body

{
  "ok": true
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |

GET /api/chat/history

Retrieve paginated conversation history for a nest. Trust boundaries are preserved on historical messages.

Authentication: Required (any mode)

Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| nest_id | string | Yes | The nest to retrieve history for |
| before | string | No | Cursor for reverse-chronological pagination. Pass the ID of the oldest message from the previous page. |

GET /api/chat/history?nest_id=nest_f7a2c9e1&before=msg_abc123
