How Raptor provides structured guidance — confidence levels, recommendations, risk assessment.

Decision Support

Every governed response includes a decision_support object that provides structured guidance for the operator.

Confidence levels

The classifier assigns a numeric confidence (0.0-1.0) which maps to a categorical level:

| Level | Threshold | Meaning | Recommendation behavior |
|-------|-----------|---------|------------------------|
| CLEAR | >= 95% | Evidence overwhelmingly supports one path | Direct recommendation provided |
| RECOMMENDED | >= 80% | Strong evidence, minor uncertainty | Recommendation with basis |
| ADVISORY | >= 50% | Evidence supports direction but alternatives exist | Options presented with tradeoffs |
| INSUFFICIENT | < 50% | Not enough evidence to recommend | No recommendation; asks for more information |

Response structure

{
  "decision_support": {
    "confidence": "RECOMMENDED",
    "recommendation": "Proceed with canary deployment.",
    "basis": "All preconditions verified, artifact integrity confirmed.",
    "risk_if_wrong": "Rollback requires manual intervention (~15m).",
    "alternatives": ["Run rollback rehearsal first (adds ~5m)"]
  }
}

Fields

  • confidence — categorical level (not the raw number)
  • recommendation — single-sentence directive. Empty when confidence is INSUFFICIENT.
  • basis — why you should trust this recommendation. Evidence-grounded, not conversational.
  • risk_if_wrong — what breaks if the recommendation is incorrect. Empty when risk is negligible.
  • alternatives — 0-3 alternative approaches. Empty when there's one clear path.

Confidence rules

The decision engine applies automatic confidence rules:

  • Below 0.5: Proposed actions are downgraded to conversational responses
  • 0.5 to 0.79: Proposed actions are downgraded to clarification requests
  • 0.8 and above: Actions proceed normally through the confirmation gate

These rules prevent the system from proposing actions it isn't confident about.

Actionability

The trust_boundary.actionability field summarizes whether to act:

  • safe — verified claims + CLEAR confidence: act with confidence
  • review — mixed boundaries: review before acting
  • blocked — inferred + INSUFFICIENT: do not act without verification
