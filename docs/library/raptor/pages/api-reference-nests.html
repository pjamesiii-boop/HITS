Nests API

Nests are the primary object in Raptor. Each nest is a governed conversation container with its own history, artifacts, governance log, and verification chain.

POST /api/nests

Create a new nest.

Authentication: Required (any mode)

Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| name | string | No | Display name for the nest. Auto-generated if omitted. |

{
  "name": "Q2 Revenue Analysis"
}

Response Body

{
  "ok": true,
  "nest": {
    "id": "nest_f7a2c9e1",
    "name": "Q2 Revenue Analysis",
    "tenant_id": "tenant_abc123",
    "created_at": "2026-05-21T17:44:22Z",
    "updated_at": "2026-05-21T17:44:22Z",
    "archived": false
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |

GET /api/nests

List nests for the current tenant. Returns non-archived nests, most recent first. Cursor-paginated.

Authentication: Required (any mode)

Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| after | string | No | Cursor for pagination. Pass the ID of the last nest from the previous page. |

GET /api/nests?after=nest_f7a2c9e1

Response Body

{
  "ok": true,
  "nests": [
    {
      "id": "nest_a1b2c3d4",
      "name": "Deployment Verification",
      "tenant_id": "tenant_abc123",
      "created_at": "2026-05-21T18:00:00Z",
      "updated_at": "2026-05-21T18:15:00Z",
      "archived": false
    },
    {
      "id": "nest_f7a2c9e1",

POST /api/nests/{id}/archive

Archive a nest. Archived nests are excluded from list results but remain accessible by ID. History and governance records are preserved.

Authentication: Required (any mode)

Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| id | string | Nest ID |

Request Body

No body required.

Response Body

  "ok": true
}

| 404 | not_found | Nest does not exist |

POST /api/nests/{id}/continue

Fork a new nest from an existing nest's intent. Creates a continuation that inherits context from the source nest.

Authentication: Required (any mode)

Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| id | string | Source nest ID to fork from |

Request Body

No body required.

Response Body

{
  "ok": true,
  "nest": {
    "id": "nest_e5f6g7h8",
    "name": "Q2 Revenue Analysis (continued)",
    "tenant_id": "tenant_abc123",
    "created_at": "2026-05-21T19:00:00Z",
    "updated_at": "2026-05-21T19:00:00Z",
    "archived": false,
    "forked_from": "nest_f7a2c9e1"
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |
| 404 | not_found | Source nest does not exist |
