System & Runtime API

System endpoints provide health monitoring, runtime configuration, version information, and public transparency data. Health endpoints are designed for orchestrator probes (Kubernetes, Railway, etc.).

GET /api/health

Liveness probe. Returns success if the server process is running.

Authentication: Not required

Response Body

{
  "ok": true,
  "uptime_seconds": 86432
}

Error Codes

This endpoint does not return errors. A non-200 response indicates the server is down.

GET /api/ready

Readiness probe. Returns success when the server is ready to accept traffic. Checks database connectivity and integrity scanner status.

Authentication: Not required

Response Body

{
  "ok": true,
  "checks": {
    "database": "healthy",
    "integrity_scanner": "healthy"
  }
}

Not ready:

{
  "ok": false,
  "checks": {
    "database": "healthy",
    "integrity_scanner": "initializing"
  }
}

GET /api/health/dependencies

Per-dependency health status. Returns the health of each external dependency the server relies on.

Authentication: Required (any mode)

Response Body

{
  "ok": true,
  "dependencies": {
    "database": { "status": "healthy", "latency_ms": 2 },
    "clerk": { "status": "healthy", "latency_ms": 45 },
    "stripe": { "status": "healthy", "latency_ms": 120 },
    "openai": { "status": "healthy", "latency_ms": 89 },
    "anthropic": { "status": "healthy", "latency_ms": 67 }
  }
}

Degraded dependency:

{
  "ok": true,
  "dependencies": {
    "database": { "status": "healthy", "latency_ms": 2 },
    "clerk": { "status": "degraded", "latency_ms": 2500, "error": "timeout" },
    "stripe": { "status": "healthy", "latency_ms": 130 },
    "openai": { "status": "healthy", "latency_ms": 95 },
    "anthropic": { "status": "unhealthy", "error": "connection_refused" }
  }
}

Error Codes

| Status | Error | When |
|--------|-------|------|
| 401 | unauthorized | No valid authentication |

Authentication: Not required

Response Body

  "ok": true,

  "supported_versions": ["2026-05-09", "2026-03-15"]
}

GET /api/config/clerk

Get the Clerk publishable key for client-side authentication setup. Used by frontends to initialize Clerk without embedding the key in client bundles.

Authentication: Not required

Response Body

{
  "ok": true,
  "publishable_key": "pk_live_abc123..."
}

Authentication: Required (any mode)

    { "method": "POST", "path": "/api/nests" },

  "total": 47
}

GET /.well-known/raptor/attestation

Public build attestation. Returns a cryptographically signed attestation of the current running build. No authentication required -- this is a public transparency endpoint.

Authentication: Not required

Response Body

{
  "ok": true,
  "attestation": {
    "subject": "raptor-control-panel",
    "commit": "a1b2c3d4e5f6",
    "build_time": "2026-05-21T16:00:00Z",
    "digest": "sha256:9a8b7c6d5e4f...",
    "signature": "ed25519:...",
    "signer": "github-actions",
    "transparency_log": "https://raptor.harpyits.com/.well-known/raptor/transparency"
  }
}

GET /.well-known/raptor/transparency

Public transparency log. Returns a paginated list of governance-significant events (policy activations, integrity checks, build deployments). No authentication required.

Authentication: Not required

Response Body

{
  "ok": true,
  "entries": [
    {
      "id": "tlog_abc123",
      "type": "policy_activated",
      "timestamp": "2026-05-21T18:05:00Z",
      "digest": "sha256:a1b2c3d4...",
      "details": {
        "policy_version": 4,
        "mode": "enforced"
      }
    },
    {
      "id": "tlog_def456",
      "type": "build_deployed",
      "timestamp": "2026-05-21T16:00:00Z",
      "digest": "sha256:9a8b7c6d...",
      "details": {
        "commit": "a1b2c3d4e5f6",
        "environment": "production"
      }
    }
  ],
  "has_more": true,
  "next_cursor": "tlog_def456"
}
