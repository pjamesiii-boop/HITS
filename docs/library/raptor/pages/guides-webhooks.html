Webhook Integration

Receive real-time governance events from Raptor via HMAC-signed webhook deliveries.

Webhook Integration

Raptor dispatches webhook events when governance decisions, responses, and policy changes occur. Each delivery is signed with HMAC-SHA256 so your endpoint can verify authenticity.

1. Create a webhook endpoint

Register a URL and subscribe to the events you care about:

curl -X POST https://raptor.harpyits.com/api/webhooks \
  -H "Authorization: Bearer rpt_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-app.com/webhooks/raptor",
    "events": ["governance.allowed", "governance.denied", "response.created"]
  }'

The response includes a whsec_ prefixed signing secret. Store it securely — it is shown only at creation:

{
  "ok": true,
  "endpoint": {
    "id": "uuid",
    "url": "https://your-app.com/webhooks/raptor",
    "events": ["governance.allowed", "governance.denied", "response.created"],
    "secret": "whsec_a1b2c3d4e5f6...",
    "active": true
  }
}

Pass an empty events array to subscribe to all event types.

2. Verify HMAC-SHA256 signatures

Every webhook delivery includes two headers:

| Header | Contents |
|---|---|
| X-Raptor-Event | Event type (e.g. governance.allowed) |
| X-Raptor-Signature | HMAC-SHA256 hex digest of the request body, keyed with your endpoint secret |

Verify the signature before processing:

import crypto from "node:crypto";


function verifySignature(body, secret, receivedSignature) {
  const expected = crypto
    .createHmac("sha256", secret)
    .update(body)
    .digest("hex");
  return crypto.timingSafeEqual(
    Buffer.from(expected, "hex"),
    Buffer.from(receivedSignature, "hex")
  );
}

Always use a constant-time comparison to prevent timing attacks.

3. Event types

| Event | Fired when |
|---|---|
| governance.allowed | A governance decision permits an operation |
| governance.denied | A governance decision blocks an operation |
| response.created | A governed response is committed to the audit chain |
| execution.completed | A confirmed action finishes executing |
| policy.activated | A new governance policy becomes active |
| governance_decision | Raw governance decision event (includes operation, decision, reason) |

Event payloads are JSON objects with fields specific to the event type. The governance_decision payload includes operation, decision ("allowed" or "denied"), and reason.

4. Example Express.js handler

import express from "express";
import crypto from "node:crypto";


const app = express();
const WEBHOOK_SECRET = process.env.RAPTOR_WEBHOOK_SECRET;



app.post("/webhooks/raptor", express.raw({ type: "application/json" }), (req, res) => {
  const signature = req.headers["x-raptor-signature"];
  const eventType = req.headers["x-raptor-event"];



// 1. Verify signature
  const expected = crypto
    .createHmac("sha256", WEBHOOK_SECRET)
    .update(req.body)
    .digest("hex");



if (!crypto.timingSafeEqual(Buffer.from(expected, "hex"), Buffer.from(signature, "hex"))) {
    return res.status(401).send("Invalid signature");
  }



// 2. Parse and handle
  const payload = JSON.parse(req.body);



switch (eventType) {
    case "governance.denied":
      alertSecurityTeam(payload);
      break;
    case "execution.completed":
      updateDashboard(payload);
      break;
    case "policy.activated":
      logPolicyChange(payload);
      break;
  }



// 3. Respond 2xx to acknowledge receipt
  res.status(200).json({ received: true });
});

5. Retry behavior

Raptor retries failed deliveries once, with a 2-second delay between attempts. A delivery is considered successful when your endpoint returns a 2xx status code within 5 seconds.

| Attempt | Timing |
|---|---|
| 1 | Immediate |
| 2 | 2 seconds after first failure |

All delivery attempts are recorded and visible via the deliveries endpoint:

curl -H "Authorization: Bearer rpt_your_key" \
  https://raptor.harpyits.com/api/webhooks/{endpointId}/deliveries

6. Manage endpoints

# List all endpoints
GET /api/webhooks


Delete (deactivate) an endpoint

DELETE /api/webhooks/{id}


View delivery history

GET /api/webhooks/{id}/deliveries
